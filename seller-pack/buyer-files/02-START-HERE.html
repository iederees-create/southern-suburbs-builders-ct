Start Here — Thanks for purchasing!

You've purchased the Southern Suburbs Builders Website Template: a static HTML/CSS/JavaScript website template for construction and renovation businesses, including a working Renovation Scope & Budget Planner tool. This guide gets it running in a few minutes. It's a digital download — no physical item is shipped.

Important: Every business name, phone number, statistic, testimonial, licence statement, and insurance statement in this template is fictional sample content. You must replace it with your own accurate information before publishing a live site. See disclaimer.html and terms.html in the template.

Step 1 — Download and extract the files

Download 01-SOUTHERN-SUBURBS-BUILDERS-TEMPLATE.zip from your Etsy purchase and extract (unzip) it. You'll get a folder of plain HTML/CSS/JS files — no build tools or installation required.

Step 2 — Preview it locally

Double-click index.html to open it in your browser, or (recommended, for full functionality) run a simple local server from that folder, e.g. python3 -m http.server 8000, then visit http://localhost:8000/.

Step 3 — Rebrand it (site-config.js)

Open site-config.js in any text editor. This one file controls: business name, logo text, tagline, phone, WhatsApp number, email, address, hours, service areas, services, testimonials, FAQs, team, social links, the map embed URL, and the three colour themes. You should not need to touch index.html, style.css, app.js, or planner.js for ordinary changes. Full field-by-field detail is in 03-COMPLETE-BUYER-GUIDE.html.

Step 4 — Configure the Renovation Scope & Budget Planner

The planner section of site-config.js controls every rate, finish-level multiplier, trade add-on percentage, complexity multiplier, currency, and contingency percentage the Planner uses. Set planner.budgetEnabled: false to turn off numeric budget estimates entirely — the tool will still produce a scope, trade checklist, and photo checklist. Every figure the Planner outputs is a preliminary, non-binding estimate — see the Estimate Disclaimer page included in the template.

Step 5 — Choose a theme

Set activeTheme in site-config.js to "concrete-brass", "cape-clay", or "blueprint-navy" — or edit the colour values directly to create your own.

Step 6 — Replace images

The project gallery ships with clearly labelled placeholder cards ("Replace with a real project photo"), not real photography. Once you have real project photos, set the image field on each entry in the gallery array in site-config.js to your image's file path.

Step 7 — Publish it

Upload the folder to any static host — GitHub Pages, Netlify, Vercel, or your existing web host all work, since this is a static site with no backend or database. See the Deployment section of the Complete Buyer Guide for step-by-step instructions.
What is NOT included: web hosting, a domain name, or installation/setup services. "Hosting" is the server that serves your files to visitors; a "domain" is your website address (e.g. yourbusiness.com). You will need to arrange both yourself — many hosts (like GitHub Pages) offer a free tier suitable for a static site like this one.
