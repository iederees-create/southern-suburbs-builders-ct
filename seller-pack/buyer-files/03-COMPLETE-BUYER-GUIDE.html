What you purchased

A digital download: the complete source code for a static (no backend, no database, no build step) website, including a working configuration system, three colour themes, and the Renovation Scope & Budget Planner tool. No physical item is shipped. Delivery is via digital file download only.

A modern browser (Chrome, Firefox, Safari, or Edge) is required to view the site; no particular buyer coding experience is required for basic rebranding beyond editing a JavaScript file in a text editor.

Renovation Scope & Budget Planner — configuration

All planner behaviour lives under planner in site-config.js:

KeyPurpose
budgetEnabledSet to false to hide all numeric budget figures. The tool still returns scope, trade checklist, assumptions, and photo checklist.
currency{ code, symbol, locale } — change this to match your local currency. The template ships with ZAR (R) as an illustrative example.
contingencyPercentPercentage added to the top of the estimated range as a buffer.
roundToFinal figures are rounded to the nearest multiple of this number.
projectTypesPer-project-type unit (sqm or linear-meter), rateMin/rateMax, and default trades. These sample rates are illustrative only — replace them with your own researched pricing before publishing.
finishMultipliersMultiplier applied per finish level (Essential/Standard/Premium/Custom).
tradeAddOnPercentPercentage uplift applied per selected trade (demolition, plumbing, etc).
complexityMultipliers for site access, storey count, and occupancy.
assumptionsBaseStatic assumption lines shown with every result.
photoChecklistsPer-project-type photo checklist shown in the results.
The Planner's output is always a preliminary, non-binding estimate — never a quotation or contract. This is stated on the Planner section of the site, in every generated summary, and on the dedicated Estimate Disclaimer page (disclaimer.html). Do not remove this disclaimer language when customising the template.

WhatsApp and email handoff

The Planner and quote form assemble a WhatsApp message or email (via mailto:) from the visitor's own input, but nothing is sent automatically — the exact message is shown in an on-screen confirmation dialog first, and only sent if the visitor clicks "Confirm & Send." There is no backend, so no data is transmitted to or stored by any server operated by you or the template author.

Deployment

This is a static site — any of the following work:

  • GitHub Pages (free): push the folder to a GitHub repository and enable Pages in the repository settings.
  • Netlify / Vercel (free tiers available): drag-and-drop the folder or connect a Git repository.
  • Traditional web hosting: upload the folder's contents via FTP/SFTP or your host's file manager.

Hosting and a domain name are not included in this purchase. "Hosting" is the server storage/bandwidth that serves your site to visitors; a "domain" is the address visitors type (e.g. yourbusiness.com). Both are arranged separately, by you, with a provider of your choice.

Testing

The Planner's calculation logic ships with an automated test suite. If you have Node.js installed, run npm test from the template folder to verify it after making changes.
