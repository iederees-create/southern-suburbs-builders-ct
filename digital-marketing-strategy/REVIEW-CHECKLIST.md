# Review Checklist — Strategy Changes

Use before committing marketing edits on `work/digital-marketing-strategy`.

---

## Strategy quality

- [ ] Correct audience (builders, renovation contractors, related trades, designers serving them)
- [ ] One clear objective for the change
- [ ] Campaign narrative preserved: **From vague enquiries to build-ready leads**
- [ ] Positioning preserved: lead-generation / project-qualification system — not merely a brochure site
- [ ] Channel-specific wording (not identical spam across every network)

## Creative craft

- [ ] Useful hook
- [ ] Clear CTA
- [ ] Correct destination for the funnel stage
- [ ] Mobile-readable on-image / caption text
- [ ] Accurate alt text where media is described

## Links and destinations

- [ ] No generic Etsy shop link pretending to be the product listing
- [ ] `EXACT_ETSY_PRODUCT_URL_PENDING_PUBLICATION` preserved until public listing exists
- [ ] Portfolio / blog placeholders preserved until routes exist
- [ ] Live demo claims not invented
- [ ] Day 7 Buy / Email 5 purchase only when exact Etsy URL is public
- [ ] Etsy buttons remain hidden pre-publication

## Compliance and honesty

- [ ] No unsupported claims
- [ ] No fake scarcity
- [ ] No fake testimonials, ratings, or sales results
- [ ] No guaranteed leads / guaranteed estimate accuracy
- [ ] Preliminary estimate disclaimer included when budget/planner outputs are mentioned
- [ ] Demo brand treated as fictional sample content
- [ ] Actual screenshot requirements identified for product-UI posts
- [ ] No fake screenshots

## Measurement

- [ ] UTM naming consistent **if** UTM fields are present in the edited file
- [ ] No fabricated KPI benchmarks
- [ ] A/B test metrics are observable, not invented winners

## Status accuracy

- [ ] Correct pre-publication vs post-publication status
- [ ] Udemy correctly marked as future manual work (`UDEMY_COURSE_URL_PENDING`)
- [ ] `CURRENT-STATUS.md` updated if readiness changed
- [ ] `STRATEGY-INDEX.md` only links files that exist

## Git hygiene

- [ ] Branch is `work/digital-marketing-strategy`
- [ ] No website source files staged
- [ ] No secrets, `.env`, credentials, or personal files staged
- [ ] Commit message is descriptive
- [ ] Push target is only `origin/work/digital-marketing-strategy`
