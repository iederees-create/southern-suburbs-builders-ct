Construction Quote Readiness Checklist

What you need before a renovation or building price is meaningful

Project Basics

  • Project type (reno / extension / new build / repair / multi-area)
  • Suburb / service area
  • Property type (house, flat, commercial unit, etc.)
  • Occupied or vacant during works

Size & Drawings

  • Approximate dimensions or room count
  • Existing drawings / sketches available?
  • Photos of current conditions

Scope Drivers

  • Finish level (essential / standard / premium)
  • Demolition extent
  • Plumbing changes
  • Electrical changes / capacity concerns
  • Structural changes / openings
  • Waterproofing needs
  • Roofing involvement
  • Flooring scope
  • Painting / finishing scope

Site & Logistics

  • Access / parking / carry distances
  • Working-hour constraints
  • Preferred start date / timeline
  • Target budget posture (range known or unknown)

Compliance & Site Visit

  • Known approvals / body-corporate or HOA rules
  • Site-visit preferred dates
  • Decision-maker contact details
  • Additional notes / constraints

Photo Checklist (attach with your enquiry)

  • Wide shot of each work area
  • Problem details (damage, damp, cracks)
  • Access path from the street
  • Electrical distribution board (if relevant)
  • Existing finishes to match or replace
